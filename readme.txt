Admin-managed sponsors logos, event banners, and podcast tiles for NYDLA via [NYDLA-CMSP].

== Description ==

NYDLA CMSP (content-management shortcode plugin) by Bez Leda Studios.

* Sponsors — logo gallery
* Events — banner cards
* Podcasts — tiles with category filters

Shortcode: `[NYDLA-CMSP type="sponsors"]` | `events` | `podcasts`

Not used for the Home Page-1 sold partner carousel (that lives in the theme Customizer).
